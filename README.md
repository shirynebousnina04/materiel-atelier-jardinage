# Matériel mystère

Jeu pédagogique en français pour associer les images de 39 objets à leur nom : laboratoire (27), aquarium (6), jardinage (6).

## Jouer

https://shirynebousnina04.github.io/materiel-atelier-jardinage/

Choisir une image, puis son nom. Séries de six objets, correction immédiate et bilan de fin de partie. Interface adaptée aux téléphones, tablettes et ordinateurs. Aucun compte, cookie, publicité ou collecte de données.

## Fichier autonome

Le fichier `index.html` contient le jeu, les styles et les 39 images extraites du PDF pédagogique fourni. Il fonctionne aussi hors connexion : télécharger le fichier, puis l’ouvrir dans un navigateur. Les images conservent les droits de leurs auteurs.

## Hébergement

GitHub Pages publie la branche `main`, dossier racine (`/`). Pour actualiser le jeu, remplacer `index.html` dans le dépôt.
